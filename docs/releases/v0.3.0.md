# TULLIP v0.3.0 — Your own private PIN

TULLIP now has its own six-digit app PIN and a companion website introducing
Lumi, an original pink tulip character. The supplied arcade launcher logo and
the owner's original decorative tulip remain unchanged.

- Set and confirm a separate TULLIP PIN without configuring a phone screen lock.
  Change or disable it only after entering the current app PIN.
- Native protection covers the journal on background, manual lock and restart.
  Wrong attempts trigger a persisted cooldown. Only a random salt and a derived
  verifier are stored privately; the PIN is never passed to JavaScript or exported.
- An enabled older device-credential lock requires one authenticated transition
  before enrolling the new PIN. Cancelling keeps the journal protected.
- The website explains accounts, wish jars, exports and privacy using labelled
  sample data. Its savings example never connects to a bank or changes app data.

This remains a debug testing release. The SQLite database is not encrypted.
There is no account-based PIN recovery; keep a private backup and remember your
PIN. Do not uninstall a journal containing your only copy of records. Android
receipt image files need a separate private copy; JSON contains their metadata.

Verification and the final APK checksum will be recorded after the production
web build, Android SDK build and actual emulator tests complete. Physical-phone
testing and the complete supported Android version matrix are NOT VERIFIED.
