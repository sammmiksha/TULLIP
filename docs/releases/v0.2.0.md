# TULLIP v0.2.0 — Android testing release

TULLIP is a local-first money journal with account-aware savings, animated wish
jars and a softer lavender-and-cream interface featuring the supplied arcade
logo and original supplied tulip artwork. No online account, analytics, bank
connection or cloud service is required.

## What changed

- Separate accounts from payment methods. UPI uses its underlying bank account;
  card purchases create liabilities, and bill transfers avoid a second expense.
- Allocate real funds to wish jars, release some or all savings, and inspect
  persistent source-account history. Corrections retain the original entries.
  Linked purchases and refunds reconcile with shared dashboard/report totals.
- Jar fill follows actual reserved savings, with accessible progress labels,
  restrained milestone feedback and reduced-motion support.
- Choose a nickname, complete first-launch setup, replay a skippable walkthrough,
  personalize display preferences and browse compact calendar indicators.
- Optional app lock uses Android's real screen-lock credential, with a native
  privacy shield on restart and when the app leaves the foreground.
- Export monthly PDF/CSV statements, separate savings history and JSON backups.
  Android sharing opens only after an explicit export action.

## Before installing

This is a **debug-signed testing build**. Storage is **not encrypted**; app lock
guards casual access and does not replace Android device security. Back up
before updating. Do not uninstall existing records to resolve a signature error.

Historical unassigned funds require explicit account assignment. Old planning
contributions remain separate history and are not silently deducted or treated
as funded savings. JSON backups contain Android receipt metadata, not the
app-private image files; preserve those files separately when moving devices.
